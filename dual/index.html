2. Presentation API (one window drives both screens)

Run this on the top screen. If Chrome can present to the bottom screen, a picker appears; choose the bottom display. A green "Hello from the other screen" page should show up there.

3. Companion page (two windows that talk to each other)

Chrome only allows one window, so the second copy runs as a small installed app:

  1. In Chrome, open the ⋮ menu → Add to Home screen (or Install app) → Install. It's called PokéRun Screen Test and is separate from the game.
  2. Open PokéRun Screen Test from your home screen and move it to the bottom screen (AYN button → Task, or your screen-switch shortcut).
  3. Keep this page open in Chrome on the top screen.
  4. Tap "This is the top screen" here and "This is the bottom screen" in the app. Within a couple of seconds both should say Connected.
